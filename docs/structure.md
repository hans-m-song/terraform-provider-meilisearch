## Proposed edit surfaces

| Boundary | Responsibility | Expected files |
| --- | --- | --- |
| Provider integration | Shared configuration and registrations | `internal/provider/provider.go` |
| API/task support | Context, task terminal status, typed errors, necessary HTTP fallback | Small files under `internal/provider/`, split only when size warrants |
| Index settings | Terraform ownership, schema, conversion, CRUD/import | `internal/provider/index_settings_resource.go`, matching tests/examples |
| Runtime flags | Singleton adoption and field-specific flag ownership | `internal/provider/experimental_features_resource.go`, matching tests/examples |
| Webhooks | UUID lifecycle, editability, header updates and redaction | `internal/provider/webhook_resource.go`, matching tests/examples |
| Temporary credentials | Open/Close, expiry, renewal policy | `internal/provider/key_ephemeral_resource.go`, matching tests/examples |
| Operations | Ingestion and backup actions | `internal/provider/*_action.go`, matching tests/examples |
| Release compatibility | Dependency pins, build matrix, state upgrade checks | `go.mod`, `go.sum`, test tooling and automation after authorized inspection |
| Durable planning | Proposals, evidence, task states, handoff | `docs/overview.md`, `docs/structure.md`, `docs/roadmap.md`, `docs/feasibility.md`, `docs/log.md`, `docs/handoff.md` |

Resource adapters own Terraform semantics; API helpers own request fidelity and remote error handling; the task waiter owns completion and cancellation. They must not own one another's policy decisions. Provider registration and dependency changes are shared integration boundaries and must be coordinated before parallel work.
